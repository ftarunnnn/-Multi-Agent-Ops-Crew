# Phase 2 — System Architecture: Multi-Agent Ops Crew

## 1. Architectural Overview

The **Multi-Agent Ops Crew** uses a directed acyclic graph (DAG) topology designed for deterministic, resilient execution of end-to-end data analysis workflows.

```
                      ┌──────────────────────┐
                      │      USER INPUT      │
                      └──────────┬───────────┘
                                 │
                                 ▼
                      ┌──────────────────────┐
                      │    PLANNER AGENT     │
                      └──────────┬───────────┘
                                 │
       ┌─────────────────────────┼─────────────────────────┐
       │                         │                         │
       ▼                         ▼                         ▼
┌──────────────┐          ┌──────────────┐          ┌──────────────┐
│  DATA AGENT  │          │   ML AGENT   │          │RESEARCH AGENT│
└──────┬───────┘          └──────┬───────┘          └──────┬───────┘
       │                         │                         │
       └─────────────────────────┼─────────────────────────┘
                                 │
                                 ▼
                      ┌──────────────────────┐
                      │    REVIEWER AGENT    │
                      └──────────┬───────────┘
                                 │
                                 ▼
                      ┌──────────────────────┐
                      │     REPORT AGENT     │
                      └──────────┬───────────┘
                                 │
                                 ▼
                      ┌──────────────────────┐
                      │   FINAL OUTPUT (MD)  │
                      └──────────────────────┘
```

## 2. Core Agent Roles & Responsibilities

### 1. Planner Agent (`planner_agent.py`)
- **Role**: Architect & Controller
- **Responsibilities**:
  - Parses problem statement and raw input files.
  - Generates a structured execution plan (DAG) with subtasks.
  - Assigns subtasks to Data, ML, and Research agents.

### 2. Data Agent (`data_agent.py`)
- **Role**: Data Scientist & Analyst
- **Responsibilities**:
  - Performs data cleansing, null handling, and type inference.
  - Executes statistical aggregations (mean, std, correlations, CAC, NPS).
  - Identifies statistical anomalies and revenue outliers.

### 3. ML Agent (`ml_agent.py`)
- **Role**: Machine Learning Engineer
- **Responsibilities**:
  - Trains regression and trend-forecasting algorithms on sales metrics.
  - Evaluates feature importance for churn and CAC.
  - Outputs metrics (R2, RMSE, MAE, feature coefficients).

### 4. Research Agent (`research_agent.py`)
- **Role**: Domain & Benchmark Analyst
- **Responsibilities**:
  - Fetches industry benchmarks (e.g., standard B2B SaaS CAC payback, churn thresholds).
  - Retrieves contextual domain knowledge to ground data metrics in real business context.

### 5. Reviewer Agent (`reviewer_agent.py`)
- **Role**: Quality Auditor & Hallucination Guard
- **Responsibilities**:
  - Cross-checks output numbers from Data and ML agents against ground-truth data.
  - Scores outputs for accuracy, consistency, and completeness (0 to 100).
  - Rejects hallucinated claims or triggers fix loops if validation fails.

### 6. Report Agent (`report_agent.py`)
- **Role**: Executive Synthesizer
- **Responsibilities**:
  - Compiles verified insights from all agents into a publication-grade Markdown executive report.
  - Formats data visual tables, recommendations, and executive risk callouts.

## 3. Communication & State Protocol

Agents communicate via a centralized `ContextState` object using standardized JSON message schemas:

- **State Container (`ContextState`)**:
  - `task_id`: Unique execution identifier.
  - `plan`: Current execution plan generated by Planner.
  - `data_artifacts`: Cleaned dataframes and statistical summary objects.
  - `ml_artifacts`: Model coefficients and accuracy metrics.
  - `research_artifacts`: Benchmark insights and domain context.
  - `review_results`: Audit scores, warnings, hallucination status.
  - `final_report`: Markdown output string.
  - `execution_logs`: Structured timestamped event log.
